# Quant Finance AGH

We are a student science club at AGH University of Krakow, working at the intersection of quantitative finance, mathematics, statistics, machine learning, and software engineering.

Our community has two complementary tracks:

- **Quant Research:** financial models, statistics, machine learning, empirical studies, and research papers.
- **Quant Development:** C++, low-latency systems, market infrastructure, and reliable research tooling.

You can contribute to either track or both. We value careful experiments, reproducible results, readable code, and constructive review.

## Start contributing

Read the [onboarding guide](https://github.com/AGH-Quant-Finance/.github/blob/main/docs/onboarding.md), discuss an available task with its maintainer, and work through a pull request. If you have an idea of your own, use the [project-proposal process](https://github.com/AGH-Quant-Finance/.github/blob/main/docs/project-proposals.md). Members are welcome to propose and lead projects.

Our initial project ideas are Volatility Forecasting, Imperfect Volatility Hedging, Order Book Engine, and Matching Engine. Scope, leads, teams, and repository links will be added as they are agreed; these are proposed initiatives.

## Current repositories

- [webpage](https://github.com/AGH-Quant-Finance/webpage): the society website.
- [cpp-toolchain-image](https://github.com/AGH-Quant-Finance/cpp-toolchain-image): the shared C++ build environment.
- [cpp-common](https://github.com/AGH-Quant-Finance/cpp-common): shared C++ configuration and release tooling.

For coordination, start with the proposed Research projects `volatility-forecasting` and `volatility-hedging`, and a Development project `market-engine` that can contain separate Order Book and Matching Engine modules. These names describe proposed work, not existing repositories. A new repository needs an agreed team and a reasonable scope.

Use repository issues and pull requests for work and decisions that should be easy to find later. Use the society's existing Discord for introductions, questions, and everyday discussion. Ask a society administrator for an invitation. English is preferred for shared documentation; both English and Polish are welcome in conversation.

Participation on GitHub or Discord does not by itself establish formal society membership. Formal admission follows the society's regulations and Board decisions.
